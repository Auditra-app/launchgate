                🛠️
                
    Troubleshooting, Whitelisting & FAQs
    
              
    
              
    Common developer questions, false-positive handling, and environment configuration.
    
            
    
          
    

          
    
            
            
    
              
    How do I whitelist template secrets or test credentials?
    
              
    LaunchGate automatically ignores dummy values (e.g. postgres://user:password@localhost or sk-dummy-test-key). For custom test files, add the comment // launchgate-ignore on the preceding line, or configure exclusions in .launchgate-ignore in your project root.
    
            
    

            
            
    
              
    Why was an AI or email service flagged by Gate 5?
    
              
    Gate 5 checks for raw LLM SDK imports without cost/rate-limiting wrappers. LaunchGate uses token-boundary matching to prevent false positives on common words like "email" or "maintain". If you use an external gateway (like Helicone or LiteLLM), mark the gate verified in the Workspace tab.
    
            
    

            
            
    
              
    How can I run LaunchGate in headless CI/CD pipelines?
    
              
    Use the preflight CLI: node cli.js scan --read-only --fail-on-p0. This command scans the repository without writing any files and exits with status code 1 if any P0 blockers are present, perfectly integrating into GitHub Actions, GitLab CI, or pre-push hooks.
    
            
    

            
            
    
              
    Where is feedback sent and what telemetry is collected?
    
              
    LaunchGate stores diagnostics strictly to your local machine at ~/.launchgate/feedback.jsonl. When you click Open GitHub Issue or Send via Email, only sanitized counts, framework names, and system versions are transferred. Zero source code or secret tokens are ever sent.
